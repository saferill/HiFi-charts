# HiFi Charts (`HiFi-charts`)

Automated trending music chart playlists for **[HiFi Music](https://github.com/saferill/HiFi)**.

## Endpoint
- **Playlists JSON**: [`api/playlists.json`](./api/playlists.json)
- Automatically synchronized every 12 hours via GitHub Actions (`sync-charts.yml`), prioritizing **Indonesia (`id`)** and **Global (`global`)** trending charts.
